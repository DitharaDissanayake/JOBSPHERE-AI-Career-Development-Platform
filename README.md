
# JOBSPHERE
## AI Smart Career Development Platform

### Project Overview
JOBSPHERE is an AI-powered career development platform designed to help students, graduates and job seekers improve their employability.

### Main Features
- User Registration and Login
- AI Career Advisor
- Resume Analysis
- Resume Building
- Interview Simulator
- Skill Development Courses
- Certificate Management
- Admin Dashboard

### Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Ollama AI
- Maven

### Project Structure
- backend/
- frontend/
- database/
- ollama/

### Setup Requirements
- Java JDK
- Maven
- MySQL
- Ollama

### Security Notice
Configure your own local credentials and environment variables.
Never publish passwords, API keys or private user data.
